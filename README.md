# 🍷 Optimización Numérica: Regresión Lineal y No Lineal Múltiple

Este repositorio contiene el código fuente para el proyecto de ajuste de datos mediante optimización numérica de segundo orden. Comparamos el rendimiento algorítmico del **Método de Newton** frente a **Trust Region (Levenberg-Marquardt)**.

## 🛠️ Tecnologías y Flujo de Trabajo
1. **Python (NumPy, Pandas, Scikit-Learn):** Data wrangling (eliminación de nulos), estandarización Z-score, e implementación desde cero de los algoritmos de optimización.
2. **Power BI:** Visualización avanzada de las curvas de convergencia y dispersión.
3. **LaTeX:** Redacción del paper académico final.

## 📂 Contenido del Repositorio
* `optimizacion_algoritmos.py`: Código principal en Python.
* `WineQT.csv`: Dataset original de Kaggle.
